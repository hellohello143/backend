# Third-party components

- Kuma Capture and its ShareX adaptation are GPL-3.0-or-later. The source is in [hellohello143/backend](https://github.com/hellohello143/backend). The capture workflow in `src/capture.rs` is adapted from ShareX. ShareX copyright (c) 2007–2026 ShareX Team. [Pinned ShareX source](https://github.com/ShareX/ShareX/tree/08bfff15e748a945944e609aca7faffbe888c7af). ShareX's own executable is not bundled.
- The portable OBS Studio 33.0.1 runtime is shipped as a separate process. Its archive includes OBS's license and original assets. [Release, upstream source and build links](https://github.com/obsproject/obs-studio/releases/tag/33.0.1), [exact OBS commit](https://github.com/obsproject/obs-studio/tree/65c320b46e1af5c7a555161aea6182cdf7a8c524), [exact obs-websocket commit](https://github.com/obsproject/obs-websocket/tree/e28f84975984340e84fc4879cfc05741cc0afde1). When building OBS source, initialize the release submodules and use the upstream build scripts.
- The optional storage worker is rclone v1.76.0 (MIT). Its license is included. [Exact rclone source and build instructions](https://github.com/rclone/rclone/tree/v1.76.0).
- The installer uses NSIS and includes the Microsoft Visual C++ x64 redistributable. See `packaging/dependencies.json` for exact downloads and checksums. Rust libraries are pinned in `Cargo.lock`.
- The illustrated bear is original app artwork. Kuma Capture is an independent project.
